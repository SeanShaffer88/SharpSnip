# Description

**SharpSnip** is a free, offline Windows screenshot tool built around an element picker. Hover any control or window, click, and capture exactly that rectangle. Also region, window, single-monitor and all-monitor capture with mixed-DPI support, a capture delay for transient menus, and a compact annotation editor.

GitHub repo description: *Offline Windows screenshot tool with a UI-element picker, multi-monitor capture, delay timer and mini editor. .NET 8 + WPF, no third-party packages.*
