**Snipit** is a free, offline Windows screenshot and screen-recording tool built around an element picker. Hover any control or window, click, and capture exactly that rectangle. Also region, window, freehand, single-monitor and all-monitor capture with mixed-DPI support, MP4/GIF recording with system sound, microphone and webcam overlay, a capture delay for transient menus, and a compact annotation editor.

GitHub repo description: *Offline Windows screenshot & recording tool: UI-element picker, multi-monitor capture, MP4/GIF recording with audio and webcam overlay, workflows, delay timer and mini editor. .NET 10 + WPF; bundles LGPL FFmpeg for export.*
